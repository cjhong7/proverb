# 📜 알쏭달쏭 속담 퀴즈

초등학생을 위한 속담 학습 웹 게임입니다.

배포 주소: https://cjhong7.github.io/proverb/

---

## 게임 개요

속담의 **뜻**을 보고 알맞은 **속담**을 4개 보기 중에서 선택하는 퀴즈 게임입니다.  
MediaPipe Hands 손 제스처로 방향(N/E/S/W)을 가리켜 정답을 선택합니다.

---

## 레벨 구성

| 레벨 | 대상 | 정답 점수 | 오답 감점 | 속담 수 |
|------|------|-----------|-----------|---------|
| 저학년 | 초등 1~2학년 | +4점 | -2점 | 60개 |
| 중학년 | 초등 3~4학년 | +6점 | -3점 | 60개 |
| 고학년 | 초등 5학년 이상 | +8점 | -4점 | 60개 |

- 제한 시간: 60초
- 문항 수: 최대 20문제

---

## 주요 기능

- 손 제스처 인식 (MediaPipe Hands) — 카메라로 손가락 방향 감지
- 전통 가야금 BGM (Web Audio API — 삼각파 + 장구 리듬)
- 온라인 점수판 (Google Sheets 연동)
- 반응형 디자인 (모바일·태블릿·PC 지원)
- 오답 가중 출제 (틀린 문제 재출제 확률 증가)
